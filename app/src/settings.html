取词与兼容性

哪些应用需要兼容性设置？

关闭兼容复制后，Excel、PDF 阅读器、微信、资源管理器等不支持无障碍取词的应用可能不再弹窗。终端和 VS Code 等编辑器始终不使用兼容复制；VS Code 需把 editor.accessibilitySupport 设为 on 才能取词。
